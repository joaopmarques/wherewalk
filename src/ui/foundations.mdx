# Foundations

The tokens live in `src/ui/tokens.css`, in three tiers.

1. **Primitives** are raw values. Only tier 2 reads them.
2. **Semantic roles** use shadcn names. Components read only these.
3. **Utilities** are the Tailwind classes made from tier 2, such as `bg-card` or `text-primary-foreground`.

A redesign changes tiers 1 and 2. Components do not change.
